API documentation

Every SMMSOFT account gets its own API key (see API Access in your platform dashboard). Keep it secret — anyone holding your key can send SMS using your credits.

Send an SMS

POST /api/send.php

FieldRequiredNotes
apikeyYesYour API key (or send the header X-Api-Key)
numberYesOne Philippine number, or many separated by commas (max 1,000 per call). Format: 09xxxxxxxxx
messageYesYour text. Long messages split into parts; each part costs credits.
kindNoregular (default), priority, or otp
otp_codeNoFor kind=otp: your own code; replaces {otp} in the message. Omit it and one is generated for you.
curl -X POST https://YOUR-PLATFORM-DOMAIN/api/send.php \
  -d "apikey=YOUR_API_KEY" \
  -d "number=09171234567" \
  -d "message=Hello from SMMSOFT API"
{"ok":true,"sent":1,"cost":1,"balance":99,"message_ids":[12345]}

Errors

Errors return JSON with an HTTP status code:

{"ok":false,"error":"Insufficient credits..."}
HTTPMeaning
401Missing or invalid API key
402Insufficient credits for this send
403Account suspended
422Invalid number or empty message
502Sending network error — not charged

Note: messages starting with the word TEST are rejected — the network silently ignores them, so we block them up front instead of charging you.
