One request

A checkout code in one request.

Your system generates the order or the login; SMMSOFT delivers the code. Use kind=otp and the {otp} placeholder, and the platform fills in a fresh code.

$ curl -X POST https://YOUR-PLATFORM/api/send.php \
  -d "apikey=YOUR_API_KEY" \
  -d "number=09171234567" \
  -d "kind=otp" \
  -d "message=Your code is {otp}. Never share this code."

{ "ok": true, "sent": 1, "cost": 2, "balance": 848 }

FAQ

Questions from online stores.

How do OTPs work here?

Send kind=otp in the API, or pick the OTP type in the dashboard. Write {otp} in the message and a code is generated for you, or pass your own code. OTP costs 2 credits per part because it rides the priority route.

Can I start without a developer?

Yes. Order updates and promos can be sent from the dashboard or by CSV upload. The API is for when your store system should send automatically.

Am I charged for failed messages?

No. When the network reports a message as failed, its credits are refunded to your balance.

Can I send promos to anyone?

Send promos only to customers who agreed to hear from your shop — your buyers and followers. Unsolicited blasts to bought lists hurt your shop’s reputation and can get numbers blocked.

What does one order update cost?

A regular message of up to 160 characters costs 1 credit — ₱0.65 — per recipient.
