FAQ

Questions from schools.

Can we send a class suspension to all parents at once?

Yes. Send to your whole parent group from the dashboard, or pass the numbers in one API call. Each parent is charged as a normal SMS.

Can attendance alerts show each student’s name and time?

Yes. Your gate system sends one API message per tap with the student’s name and time, or you upload a CSV where every row has its own message.

Do we need a developer?

Not for the dashboard or CSV sending — the registrar’s office can do both. Attendance automation from a gate system needs your IT staff or vendor to connect the API.

Can we write messages in Filipino?

Yes, in standard letters. Keep messages plain-text so they display correctly on any phone.

How do we pay?

Buy credits with GCash from the platform Credits page and submit your reference number; credits are added once the payment is verified.
