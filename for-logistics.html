Send from the dashboard.

Export your list from Excel or Google Sheets as a CSV — the number in the first column, the message in the second — and upload it. Every row can carry a different message.

todays-deliveries.csv

numbermessage
09171234567Hi Ana, delivery today 9AM-12NN. Rider will call when near.
09181234567Hi Jose, delivery today 1PM-4PM. Rider will call when near.
09271234567Hi Liza, delivery today 4PM-6PM. Rider will call when near.

Invalid rows are skipped. Every message and its status appear in your message history.

One request

A status update from your system.

When a parcel changes status, your system sends one API call. The customer is updated in seconds, and the message is recorded in your history.

$ curl -X POST https://YOUR-PLATFORM/api/send.php \
  -d "apikey=YOUR_API_KEY" \
  -d "number=09171234567" \
  -d "message=Your parcel is out for delivery today."

{ "ok": true, "sent": 1, "cost": 1, "balance": 1204 }

FAQ

Questions from couriers.

Can each customer get their own time window?

Yes. Upload a CSV where every row has that customer’s own message, or send one API call per status change with the window in the text.

Can we remind COD customers to prepare payment?

Yes — include it in the out-for-delivery message, like the sample on this page. It cuts failed first attempts.

How do we know a notice was delivered?

Every message’s status — Queued, Sent, Failed or Refunded — is in your message history, and failed messages are refunded per network report.

What does one update cost?

1 credit per message part, per recipient — ₱0.65 for a normal-length update.

Do we need our own system to use this?

No. Dispatchers can send the day’s notices from the dashboard or a CSV upload. The API is for automatic status updates.
